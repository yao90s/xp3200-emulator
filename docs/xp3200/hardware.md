# XP3200 硬件连接

本文记录 XP3200 主控（EPSON S1C33L05）与各外设的地址/IO 连接，
内容来自真机镜像分析、逻辑分析仪抓取和模拟器实现（`hw/s1c33/xp3200.c`）。

## 1. 总览

```
                     +---------------------------+
                     |     EPSON S1C33L05        |
                     |  CPU / LCDC / NAND / SIO  |
                     +--+-----+-----+-----+------+
                        |     |     |     |
        NOR 1MB --------+     |     |     +---- NAND 128MB (K9F1G08U0D)
        SDRAM 8MB ------------+     |          0x04000000 数据口
        LCD 320x240 ----------------+          0x04000100 控制口
        键盘 5x14 ------------------+
        SD 卡 (SPI) ----------------+
        VS1003B (SPI) --------------+
        USB 1.1 --------------------+
```

## 2. 地址空间

| 区域 | 地址 | 说明 |
|---|---|---|
| NOR FLASH | `0x00000000` | 1 MiB，`-bios` 加载 |
| IRAM | `0x00000000`–`0x00003FFF` | 片内 16 KiB，启动栈顶 `0x00003F80` |
| SDRAM | `0x02000000` | 8 MiB（HY57V641620HGT） |
| 板级 IO | `0x01000000` | USB 状态/控制 |
| 端口/键盘 | `0x00040000`–`0x0004FFFF` | P0–P3、K5/K6、端口中断 |
| 板级锁存/键盘行 | `0x00300000`–`0x00300FFF` | `0x300020`、`0x300046`、`0x300F46`、ADC |
| LCD 控制器 | `0x00380000` | LCDC 寄存器 |
| IVRAM | `0x003C0000` | 40 KiB 显示缓存 |
| SPI（SD/VS1003） | `0x003A0000` | SPIRD/SPITD/CTRL/WAIT/STATUS/INTCTL |
| NAND | `0x04000000` | 数据窗口 4 KiB；控制口 `0x04000100`–`0x04000105` |

## 3. 键盘（5 行 × 14 列，67 键）

| 信号 | 地址/端口 | 说明 |
|---|---|---|
| 行选通 | `0x00300F46` bit0–4 | 低有效，一次驱动一行 |
| 列输入 K5 | `0x00402C1` bit0–3 | 列 0–3（经行选通门控） |
| 列输入 P0 | `0x00402C0` bit4–6 | 列 4–6（直连键盘） |
| 列扩展 | `0x00300F46` bit5–10 | 列 5–10 |
| 列扩展 | `0x00300020` bit0–2 | 列 11–13 |
| K6 | `0x00402C4` | bit4：唤醒/第 5 行/键码 bit4 |
| 键盘功能 | `0x00402C0`/`0x00402C3` | K5/K6 功能选择 |
| 端口中断 | `0x00402C6`–`0x00402CF` | 选择/条件/掩码 |
| 键码 | K5[3:0] + K6.4 | 5 位；位置 = 14×(行−1) + 列位索引 + 1 |

- 键盘由 Timer3 去抖 + FK0 中断（EIR0）唤醒；
- 完整 67 键映射见 [keyboard.md](keyboard.md)。

## 4. NAND FLASH（K9F1G08U0D，128 MiB）

| 信号 | 地址 | 说明 |
|---|---|---|
| 数据口 | `0x04000000` | 4 KiB 窗口，按 8 位访问 |
| CE | `0x04000100` | 片选 |
| ECC 就绪 | `0x04000101` | 读 ECC 状态 |
| ECC 使能 | `0x04000102` | 硬件 ECC |
| 模式 | `0x04000103` | 总线模式 |
| ECC 数据 | `0x04000104` | 6 字节 ECC |
| CLE | `0x00402D5` bit6 | 命令锁存（P1D） |
| ALE | `0x00402D5` bit5 | 地址锁存（P1D） |
| R/B | `0x00402D9` bit6 | 忙闲（P2） |

- 页 2 KiB、OOB 64 B；主 OS 位于 NAND `0x7C80000`，启动时由 NOR 引导程序
  搬到 SDRAM `0x02100000`（映射：VA = NAND 偏移 − `0x7C80000` + `0x02100000`）。

## 5. LCD（320 × 240，4 bpp，16 级灰度 STN）

| 寄存器 | 偏移 | 说明 |
|---|---|---|
| HNDP | `0x0040` | 水平非显示区 |
| HSIZE | `0x0042` | 水平尺寸 |
| VNDP | `0x004A` | 垂直非显示区 |
| VSIZE | `0x004C` | 垂直尺寸 |
| MODE0 | `0x0200` | 显示模式 |
| MODE1 | `0x0202` | 空白/反色等 |
| SADDR | `0x0210` | 显示起始地址 |
| LUT | `0x0400`–`0x0800` | 调色板，每项 4 字节 |

- 基址 `0x00380000`，显示缓存 IVRAM `0x003C0000`（40 KiB）；
- 面板无触摸层，按键为唯一输入。

## 6. SD 卡（S1C33L05 MMC，SPI 模式）

| 寄存器 | 偏移 | 说明 |
|---|---|---|
| SPIRD | `0x0000` | 接收数据 |
| SPITD | `0x0002` | 发送数据 |
| CTRL | `0x0004` | ENA/MCBR/CPOL/CPHA/BPT |
| WAIT | `0x0008` | 等待 |
| STATUS | `0x000A` | RDFF/TDEF/BSYF |
| INTCTL | `0x000C` | 中断控制 |

| 信号 | 地址 | 说明 |
|---|---|---|
| 片选 | `0x00300022` bit0 | 低有效（与 VS1003 共用端口） |
| P3 功能 | `0x00300046` | P3.0–P3.2 复用为 SPI |
| 卡检测 | `0x00300022` bit2 | 0 = 在位（固件 `0x7D128E8` 去抖） |

- 协议：命令 5 字节 + 1 dummy，R1 晚一个字节；CSD/CID 前有 `0xFE` 令牌；
  CMD17 参数是字节地址（扇区 × 512）；数据块 CRC16（CCITT `0x1021`）；
- 固件把 CSD 的 16 字节反转后按小端解析 `C_SIZE`/`C_SIZE_MULT`，
  镜像生成工具据此构造 CSD（见 [sdcard-tool.md](sdcard-tool.md)）。

## 7. VS1003B 音频

- 与 SD 卡共用 SPI 块 `0x003A0000`；
- 片选/端口选择：`0x00300022`（bit5 高 = SCI 命令口，bit0 高 = SDI 数据口），
  板级锁存 `0x00300020` 参与选择；
- 数据请求 DREQ：`0x00402D9` bit4（P2.4），固件据此节拍向解码器推数据；
- 模型把压缩流通过管道交给外部播放器（如 `ffplay`）解码。

## 8. USB 与供电

| 信号 | 地址 | 说明 |
|---|---|---|
| USB 状态 | `0x01000022` | bit7 = 已连接 |
| USB 控制 | `0x01000082` | 控制寄存器 |
| USB 数据 | `0x01000083` | 数据寄存器 |
| USB 状态 | `0x01000084/85` | 高/低字节 |

- USB 1.1 mini-B，仅作 U 盘连接/供电；模拟器未实现 USB 设备模式；
- 供电：2 节 7 号电池，或从 USB 取电；电池电压经 ADC 检测。

## 9. 其他

- 串口/红外：SIF0–SIF3（`0x0040xxxx`），模拟器只实现启动所需状态；
- 定时器：Timer0/1（16 位比较）、Timer2/3/4（8 位）、Timer8（4 路）；
- RTC：IRAM 末尾 4 字节保存时间戳（`0x003C3FFC`）。

### 看门狗（16TM0）

| 项目 | 值 |
|---|---|
| 寄存器 | `0x0048186`（16TM0 CTRL，块基址 `0x0048180`） |
| 喂狗动作 | 写 `0x23` |
| 喂狗周期 | 固件约 10 ms 一次（喂狗代码 `0x7CF2770`） |
| 超时 | 约 2 s，超时整机复位 |

- 固件在 OS 主循环里定时写该寄存器，程序自己写也能续命；外部程序只要不喂狗，
  约 2 秒后整机重启（真机与模拟器一致）。
- 模拟器在 `hw/s1c33/xp3200.c` 的 `xp3200s_timer16_write_byte()` 中识别
  “`offset == 16TM0 CTRL` 且写入 `0x23`”，重启 2 秒虚拟定时器；到期用
  `qemu_system_reset_request()` 复位整机并打印 `watchdog timeout`。
